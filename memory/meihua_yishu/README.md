## 使用原则(对标缠论"原文结构 vs 实战过滤")

断卦时必须区分三层,不可混同:

1. **原文结构(硬骨架)**: 先天八卦数、体用定义、五行生克、互变取法、旺衰应期 —— 这些是《梅花易数》原文的确定规则,不可临时更改。
2. **类象取用(需选择)**: 万物类象一卦可对多象,断卦时须结合**所占之事(用途)**择取最贴切的一象,不可随意堆砌。
3. **外应/克应(辅助)**: 三要十应、静观外物只作辅助印证,不能单凭外应推翻体用生克主结论。

## 断卦第一铁律

**体为主,用为事;生体为吉,克体为凶。** 全部吉凶推理都先落到"体卦被生还是被克"这一根主线上,再论旺衰、互变、应期。任何花哨类象都不能翻案体用生克的主结论 —— 正如缠论里"级别否决不能被小级别翻案"。

## 一句话心法

- 起卦定象,体用定吉凶,互变定过程,旺衰定力度,应期定时间,外应定印证。
- 一事一占,占后即断,不重复起卦问同一事。
- 卦无吉凶,吉凶在生克与旺衰;象无善恶,善恶在体用与所问。
