# 08 断卦 SOP 与经典案例

## 一、完整断卦流程 SOP(对标缠论"连续多日多级别 SOP")

按顺序走,缺一步则结论降级为"暂断/存疑":

```text
① 明事      —— 先问清"占何事、谁来占、主体是谁"。一事一占。
② 起卦      —— 按 01 取上卦、下卦、动爻(记录取数来源:时间/数字/声音/物象)。
③ 排三卦    —— 写出 本卦(上下)、互卦(2345爻)、变卦(动爻变)。
④ 定体用    —— 动爻所在经卦为"用",静者为"体";体=自身,用=事/对方。
⑤ 定五行    —— 体、用、互(体互/用互)、变 各卦的五行(见 02)。
⑥ 断生克    —— 以各卦对"体"的生克定吉凶(生体比和吉、克体凶、体生耗、体克费)。
⑦ 论旺衰    —— 按月令查体卦与克/生体之卦的旺相休囚死(见 05),定吉凶力度。
⑧ 读互变    —— 互卦断中段曲折,变卦断最终结局(尤重"变卦是否克体")。
⑨ 定应期    —— 以卦气当令 / 卦数 / 动爻数推应验时间,给区间不给铁点(见 05)。
⑩ 参外应    —— 三要十应印证(见 06),同向加强、反向提示反覆,不翻案主结论。
⑪ 出断语    —— 落到具体:吉/凶 + 在何事何方何时 + 宜忌建议。
```

## 二、断卦输出模板

```text
【所占】(何人占何事)
【起卦】取数来源 / 上卦 / 下卦 / 动爻
【三卦】本卦: ___  互卦: ___  变卦: ___
【体用】体卦=___(五行/自身)  用卦=___(五行/事)
【生克主断】用对体: ___(吉/凶)  互对体: ___  变对体: ___
【旺衰】月令: ___  体卦: 旺/相/休/囚/死  克体之卦: ___
【应期】___(季/月/日 区间)
【外应】___(如有)
【结论】吉/凶 + 具体事象 + 宜/忌
```

## 三、经典案例(邵康节《梅花易数》原著)

### 案例1:观梅占(泽火革)
- **缘起**:辰年十二月十七日申时,观梅,见二雀争枝坠地。
- **起卦**:年辰=5,月=12,日=17 → 和 34,÷8 余 2 = 兑(上卦);加申时=9,和 43,÷8 余 3 = 离(下卦)。得**泽火革**(兑上离下)。动爻 43÷6 余 1 = **初爻动**。
- **三卦**:本卦泽火革;互卦=天风姤(乾上巽下);变卦初爻动,离变艮 → **泽山咸**(兑上艮下)。
- **体用**:动爻在下卦离 → **离为用(火)**,**兑为体(金)**。
- **主断**:用离火**克**体兑金 → **凶**,体主(少女·兑)有伤。互有巽木(巽为股),变艮为少男。
- **断语**:明晚当有女子折花,为园丁逐之,惊坠**伤股**;因体金衰、火克金,不至于大凶,伤而不死。次晚果验。
- **示范点**:体用生克(火克金定凶)→ 取象(兑少女、巽股)落到"伤股"→ 旺衰(体衰但克有限)定"伤而不死"。

### 案例2:牡丹占(天风姤)
- **缘起**:巳年三月十六日卯时,同客观牡丹盛开,客问"花开如此,亦有数乎?"
- **起卦**:年巳=6,月=3,日=16 → 和 25,÷8 余 1 = 乾(上卦);加卯时=4,和 29,÷8 余 5 = 巽(下卦)。得**天风姤**(乾上巽下)。动爻 29÷6 余 5 = **五爻动**。
- **体用**:动爻五爻在上卦乾 → **乾为用(金)**,**巽为体(木)**。
- **主断**:用乾金**克**体巽木 → **凶**,花(木)当有毁。乾为马。
- **断语**:此花明日午时当为**马所践毁**。次日果有二马相斗,践花尽损。
- **示范点**:金克木定"花毁"→ 乾为马取"毁于马"→ 应期落"午时/次日"(卦数与卦气)。

### 案例3:邻人叩门借物占(以象定具体物)
- **缘起**:冬夕酉时,有叩门者,先敲**一声**而止,少顷又敲**五声**云借物。
- **起卦**:一声为上卦 → 乾(1·金);五声为下卦 → 巽(5·木)。得**天风姤**;配时定动爻。
- **推物**:乾金**短**、巽木**长**;金短木长、上金下木、金能刻木之器 —— 非斧即锄。邵子断"所借非斧即锄"。问之,果**借斧**。
- **示范点**:同一卦象,占"何物"时把类象落到器物栏(乾金器·巽木柄),用形态(短/长)推出具体物。

### 案例4:老人有忧色 / 少年有喜色(外应+人物+方位)
- **缘起**:见一老人自**巽方**来、面带**忧色**;为之占。
- **取象起卦**:老人属**乾**(老人)为一卦、巽方为一卦,配时得卦。
- **主断**:卦中克体、老人乾金逢克且卦气衰 → 断此老人数日内有灾。后果应(失食/病故一类)。
- **对照**:若见**少年有喜色**、来自吉方、卦现生体比和 → 断近日有喜庆财喜。
- **示范点**:人物(老/少)、方位(来向)、气色(忧/喜)= 三要十应的外应,与体用生克同向印证,增强断语。

## 四、断卦纪律清单(自检)

1. 是否**一事一占**、未反复起卦问同事?
2. 体用是否按"动为用、静为体"正确判定?
3. 吉凶是否**先落到体被生/被克**这条主线?
4. 是否查了**月令旺衰**定吉凶力度、没把"死囚之克"当大凶?
5. 互卦(中段)、变卦(结局)是否都读到,尤其**变卦克体**是否标为重大凶?
6. 应期是否给**区间**、区分了事之缓急单位?
7. 外应是否只作印证、没有翻案主结论?
8. 断语是否落到**具体事象 + 方位/身体/物 + 时间 + 宜忌**,而非空泛?

> 心法收束:卦定于起,断成于体用,验之于旺衰应期,印之于外应。诚则灵,静则明,一事一占,占毕即断。
