# 05 五行旺衰与应期

生克定**方向**,旺衰定**力度**,应期定**时间**。

## 一、五行生克(复习·硬口径)

- 相生:金→水→木→火→土→金(循环)。
- 相克:金→木→土→水→火→金(循环)。
- 生我者为"生体"之源(吉);克我者为"克体"之敌(凶);我生者泄我(耗);我克者被我制(小得而费力);同我者比和(吉顺)。

## 二、卦气旺衰(旺相休囚死)

以**占卦时所处季节(月令)**定卦气。某五行在当令季节为最强,依次递减:

| 状态 | 定义 | 力度 |
|---|---|---|
| 旺 | 当令(与月令同五行) | 最强 |
| 相 | 我生者当令时,我为"相"(被令所生) | 次强 |
| 休 | 生我者当令时,我已退居"休" | 中平偏弱 |
| 囚 | 我克者当令时,我为"囚" | 弱 |
| 死 | 克我者当令时,我为"死" | 最弱 |

各季当令五行:

| 季节(月令) | 当令(旺) | 相 | 休 | 囚 | 死 |
|---|---|---|---|---|---|
| 春(木) | 木 | 火 | 水 | 金 | 土 |
| 夏(火) | 火 | 土 | 木 | 水 | 金 |
| 秋(金) | 金 | 水 | 土 | 火 | 木 |
| 冬(水) | 水 | 木 | 金 | 土 | 火 |
| 四季末(辰未戌丑月·土) | 土 | 金 | 火 | 木 | 水 |

**用法**:体卦、生体卦、克体卦各查旺衰。
- 体旺 → 能担克,吉更稳、凶可扛。
- 克体之卦旺 → 凶重且实;克体之卦死囚 → "克而无力",凶可减免。
- 生体之卦旺 → 得力之助,吉实;生体之卦衰 → 有心无力,吉虚。

## 三、克处逢生 / 生处逢克(解救与反覆)

- **克体之卦,被别卦所克** → 敌被制,凶解(化凶为平)。
- **生体之卦,反被别卦克** → 恩人自身难保,吉打折。
- 逐卦串起来看这条"生克链",不要孤立看单卦。

## 四、应期推算(何时应验)

应期是梅花断卦的高级功夫,常用三条线,取其贴切者:

### 1. 以卦气/五行定季月
- 事应在**生体或用卦五行当令**之时。如体得木生,应在春或亥卯未木旺之月/日。
- 吉事应在生体之卦旺的时段,凶事应在克体之卦旺的时段。

### 2. 以卦数定数目(时间/次数)
- 取相关卦的**先天卦数**为应期数字(几日、几月、几年,视事之大小缓急定单位)。
- 常取:体卦数、用卦数、变卦数,或几卦数之和。
- 事缓以年月计,事急以日时计。

### 3. 以成卦之数 / 动爻定
- 用起卦总数、动爻数配合地支时序推应验时辰/日。

### 应期取单位的分寸
- 占天时、行人、失物等急事 → 日、时。
- 占谋事、求财、婚姻 → 月。
- 占官运、大事、宅运 → 季、年。

## 五、旺衰应期纪律

1. **先方向后力度**:未定生克方向,不谈旺衰;未定旺衰,不轻断应期。
2. **应期给区间不给铁点**:以"某五行旺月/某卦数日"给概率区间,忌拍死单一日期(对标交易里"给区间不给铁点位")。
3. **静者应迟、动者应速**:卦静(动爻少、卦气衰)则应期远;卦动、卦气旺则应期近。
