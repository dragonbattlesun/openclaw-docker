# 07 分类占断口诀

各类事项的断法要点。**通则不变**:一切先看体用生克(生体比和吉、克体凶),下列只是各类事"取象落点"的补充。

## 一、天时占
- 体用取象:离为晴、坎为雨、坤为阴、巽为风、震为雷、乾为寒/晴、艮为山云雾、兑为泽雨。
- 断法:视卦中所现之象与旺衰。离火旺主晴;坎水旺主雨雪;坤艮土多主阴晦;巽风乾寒。
- 卦中无坎无兑,虽阴无雨;坎兑重见,雨雪连绵。

## 二、人事占
- 体用比和生体 → 人事吉、和顺、有贵人。
- 克体、体生用 → 人事多阻、耗损、口舌是非(尤兑卦多口舌)。
- 互变看事之曲折与终局。

## 三、家宅占
- 体为主家/宅,用为宅之外应/事。
- 生体比和 → 家宅安稳兴旺;克体 → 宅不安、有灾病破财。
- 取象:坎宅近水/漏湿,离宅近火/口舌文书,艮宅近山/门径,坤宅田土/低平,乾宅高贵旧宅,兑宅口缺破损,震宅动/临闹市,巽宅林园。

## 四、婚姻占
- 体为所问主(自身或所托),用为婚姻对象。
- 生体比和 → 婚成且吉;克体 → 婚难成或成而不吉;体生用 → 主动追求费力。
- 用卦旺 → 对方家世强/条件好;用衰 → 对方弱。
- 卦象看人品:坤厚、兑悦(女好悦亦主口舌)、坎险、艮止(阻/迟)、离丽(美/文)。

## 五、求财占
- 体为求财人,用为财。
- **用生体 / 比和** → 得财;**体克用** → 可得财但费力(我去克取);**用克体** → 破财、求不得;**体生用** → 耗财、财外流。
- 财之多寡看用卦旺衰:用旺财大,用衰财小。
- 卦象:乾兑金财、坤艮土财、坎水财(流动/不定)、离火财(文书/明处)、震巽木财。

## 六、疾病占
- 体为病人,用为病症/病势。
- **生体比和** → 病愈、有救;**克体** → 病重、危、难治;克体之卦旺则凶甚。
- **变卦生体** → 终得愈;变卦克体 → 病转危、防不测。
- 克体之卦被制(克处逢生) → 得医得药、有转机。
- 取象定病位/病因:坎肾/血/耳,离心/目,艮脾胃/手鼻,兑口/肺/痰,乾头/骨/肺,坤腹/脾,震足/肝,巽股/气/风疾。

## 七、官讼占
- 体为己,用为对方/官司。
- 生体比和 → 讼吉、得理、有贵人;克体 → 讼凶、受制、宜和解免灾。
- 体克用 → 己方占上风但耗力;体生用 → 反助对方、破财消灾。
- 离主文书,乾主官贵,坎主险/牢狱之忧。

## 八、行人占(出行者归否)
- 体为居家占者,用为行人。
- 用生体/比和 → 行人将归、平安;克体 → 行人有阻/有险、未归。
- 用卦旺、动 → 归速;用衰、静、被克 → 归迟或有阻。
- 变卦生体 → 终归。坎多险阻,艮多止而未动,震巽主动身在途。

## 九、失物占
- 体为失主,用为失物/去向。
- 生体比和 → 可寻回;克体 → 难寻。
- **方位**:以用卦(或克体之卦、变卦)所属**方位**定物之所在(见 `02` 后天方位表)。
- **藏处取象**:坎水边/井,离明处/南向/火灶,艮山石/门旁/土中,坤田野/仓库/布帛中,乾高处/西北,兑泽边/破缺处,巽园圃/草木中,震林中/大道旁。

## 十、求名(功名/事业)占
- 体为求名人,用为功名。
- 生体比和 → 名成;克体 → 不成或有辱。
- 体克用 → 可成而费力;体生用 → 徒劳耗损。
- 离火文书/文明 → 主科甲文名;乾主官贵。应期看生体之卦旺月。

## 十一、出行/谋事/交易(通用)
- 生体比和吉、克体凶、体生用耗、体克用可成而费。
- 动卦(用)主变动方向,变卦主结局,互卦主中途。

## 通用纪律
1. 各类占**先套体用生克主结论**,再用本类取象把"吉/凶落在什么事、什么方位、什么身体部位"讲清楚。
2. 求财/求名/官讼这类**"我要得到"的占**,牢记:**生体/比和最优,体克用次之(得而费力),用克体最忌(求不得反受害)**。
3. 疾病/官讼等凶险事,**变卦克体**要明确升级为重大凶信号。
