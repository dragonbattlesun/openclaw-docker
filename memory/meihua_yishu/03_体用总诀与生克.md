# 03 体用总诀与生克断卦

梅花易数断吉凶的**主脊柱**。全部推理先落到这里,再论互变、旺衰、应期。

## 一、体用定义

一卦分上下两经卦(内外卦)。以**动爻**分体用:

- **体卦**:不动(静)的那一经卦 —— 代表**占问的人 / 主体 / 自身**。
- **用卦**:动爻所在(动)的那一经卦 —— 代表**所占之事 / 客体 / 对方**。

> 体为己,用为事;体宜旺、宜被生,用为体所用之资。

### 体用与三卦的分工

一次占卦共牵出**本卦(上下二卦)、互卦、变卦**,角色如下:

| 卦位 | 代表 | 断读 |
|---|---|---|
| 体卦 | 自身/主体 | 全局主人,宜旺宜生,忌被克被泄 |
| 用卦 | 所占之事/对方 | 事情本体,看它与体的生克 |
| 互卦(体互/用互) | 事情**中间过程** | 分体之互、用之互,应中段吉凶 |
| 变卦 | 事情**最终结果** | 看变卦是否生体、克体,定终局 |

> 断法次序:先看**用卦生克体卦**定基调 → 再看**互卦**中间波折 → 最后看**变卦**结局与应验。

## 二、体用生克总诀(核心吉凶)

以"其它各卦(用、互、变)对**体卦**的五行生克"论吉凶:

| 关系 | 含义 | 吉凶 |
|---|---|---|
| **生体** | 他卦五行生体卦 | **大吉**,得外助、顺遂、有人相扶 |
| **体生他** | 体卦去生他卦(泄气) | **耗损**,主破财、劳心、被拖累 |
| **比和** | 他卦与体同五行 | **吉**,顺利、和谐、事易成 |
| **克体** | 他卦五行克体卦 | **凶**,受阻、受害、事难成 |
| **体克他** | 体卦克他卦 | **小吉/中平**,事虽可成但费力,得而有耗 |

一句话:**生体比和吉,克体最凶,体生体克次之。**

## 三、多卦合断的权重

体卦要面对**用、互(二)、变**多个卦,把它们对体的生克综合看:

1. **生体者多** → 吉,且看谁生:用生体=事顺、互生体=中途得助、变生体=结果圆满。
2. **克体者多** → 凶,同理分段:用克体=事起即受阻、变克体=结局败。
3. **卦中有生体又有克体** → 看**旺衰**(见 `05`):生体之卦旺则以吉论,克体之卦旺则以凶论;并看克体之卦是否被别卦所克(**克处逢生/克者受制则解凶**)。
4. **体卦宜旺不宜衰**:体旺则能任克,虽逢克体亦不大凶;体衰则逢克必败,即使得生也力弱。

## 四、体用生克的经典断语(邵子原诀)

- 「体用之说,动静之机。八卦主宾,五行生克。体为主,用为事。用生体及比和,则**百事吉**;体生用及克体,则**百事凶**。」
- 「体卦为主,用卦为宾。用克体,不宜也;体克用,则事虽可求犹有阻节。」
- 「体党多而体势盛,用党多而体势衰。」—— **体党**=生体、比和之卦(体的帮手);**用党**=克体、体所生之卦(消耗体的势力)。数党之多寡定体之盛衰。

## 五、断卦第一铁律(对标缠论级别否决)

**克体不解释,先定凶;生体比和,先定吉。** 再华丽的类象都不能翻案"体被生还是被克"这条主线,正如缠论中大级别否决不被小级别翻案。类象只用来说明"吉在何处、凶在何事",不改变吉凶方向。
